Official implementation of **ReSearch** and **ReCall**, two reinforcement learning methods for improving large language models with search and tool-use capabilities.

## News
- [2025/05] 🔥 **ReCall** accepted by ACL 2025 Findings!
- [2025/04] 🔥 **ReSearch** released.
